# KSP2 Unity Tools
A collection of Unity editor scripts and the like to make developing Kerbal Space Program 2 mods easier.

## DEPRECATED
This repository has been archived as read-only and development is continued for KSP2 Redux 0.2.3+ at https://github.com/KSP2Redux/SDK.

## Installation
If you do still want to install this package for stock KSP2 0.2.2 modding, installing it in the Unity Package Manager as a package from the following Git URL: https://github.com/KSP2Community/KSP2UnityTools.git
